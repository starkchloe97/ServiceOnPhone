# ServiceOnPhone

A responsive, single-page Vue 3 website based on the structure of the supplied Samsung & LG Service Center Karachi reference capture. The project uses a refreshed teal-and-amber palette, replacement appliance-repair imagery, and a PHP/MySQL lead form backend.

## Stack

- Vue 3 + Vite (single page; no router or additional pages)
- lucide-vue-next icons
- PHP 8+ endpoint using PDO
- MySQL 8+ (MariaDB is also suitable)

## Project structure

- src/components/ — header, hero, about, statistics, services, gallery, contact, footer, WhatsApp action and callback modal
- src/config/site.config.js — central business details, displayed copy, links, images, navigation and opening hours
- src/composables/useLeadForm.js — shared form submission state and API client
- api/submit.php — validated JSON endpoint that stores submissions
- api/config/database.example.php — safe database configuration template
- database/schema.sql — database and service_leads table
- dist/ — generated by the production build (not committed)

## 1. Install and run the Vue app

Install Node.js 20 or later, then run:

    npm install
    npm run dev

Vite serves the website at http://localhost:5173.

## 2. Configure MySQL

Create the database and table by importing database/schema.sql into MySQL or MariaDB. For example, from a MySQL client:

    mysql -u root -p < database/schema.sql

Copy api/config/database.example.php to api/config/database.php and set the host, port, database, username and password for your MySQL installation.

On Windows PowerShell:

    Copy-Item api/config/database.example.php api/config/database.php

On macOS/Linux:

    cp api/config/database.example.php api/config/database.php

The real api/config/database.php is excluded by .gitignore. Never commit production database credentials.

## 3. Run the PHP endpoint locally

Open a second terminal in the repository root and run:

    php -S 127.0.0.1:8000 -t .

The Vite development server proxies /api requests to this PHP server. Submit the contact form or use the Request a call button to test a lead submission. A successful submission is inserted into the service_leads table.

Required PHP extensions: PDO and pdo_mysql. The endpoint accepts JSON POST requests, validates name and phone, validates an optional email address, limits request size, uses a honeypot field, and inserts with a prepared statement.

## 4. Rebrand the website

Edit src/config/site.config.js. It contains the business name, brand name, phone numbers, WhatsApp number and links, email, address, map link, navigation labels, hero slides, about copy, statistics, service descriptions, gallery images, contact copy, footer text and opening hours.

To change the WhatsApp destination, update contact.whatsappNumber and the two URLs in whatsapp. Use the international number without spaces or a leading plus sign in the wa.me URL. Update phoneE164 separately for the tel: links.

Replace the image URLs in the config with your own licensed images. Images are remote references so you can rebrand them without changing the Vue components.

## 5. Production build and deployment

Build the Vue app:

    npm run build

Upload the contents of dist/ to your web root. Copy the api/ directory alongside the generated index.html so /api/submit.php remains available. Create api/config/database.php on the server from the example file and enter the production MySQL credentials. Import database/schema.sql into the production database.

The root .htaccess provides the SPA fallback for Apache and blocks direct access to api/config/. For Nginx or another web server, configure an equivalent SPA fallback and deny web access to api/config/.

## API contract

POST /api/submit.php with a JSON body:

    {
      "name": "Customer name",
      "phone": "+92 300 0000000",
      "email": "customer@example.com",
      "message": "My refrigerator is not cooling.",
      "source": "contact",
      "website": ""
    }

Allowed source values are contact, callback and service. The endpoint returns JSON with success and message fields. Validation failures return HTTP 422; unsupported methods return 405; server/database errors return a generic HTTP 500 response while details are written to the PHP error log.

## Reference notes

The supplied upload was an MHTML browser capture rather than a separate reference.html file. The capture was used to follow the original section order and page structure: contact strip/navigation, hero slider, about, company numbers, six service cards, gallery, contact form and footer. The new design intentionally changes the colour palette and imagery while keeping the one-page layout and anchor navigation.
